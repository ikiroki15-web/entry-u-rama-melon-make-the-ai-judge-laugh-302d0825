## What it does

`main.ts` writes a single original one-line joke about office life to `/output/entry.txt` — under 200 characters, deterministic, no network, no secrets.

> My boss tracks my productivity in a spreadsheet, so I spend every Friday updating the spreadsheet about the spreadsheet.

## Run

```sh
node main.ts
```

This creates `/output/entry.txt` containing the joke above.
